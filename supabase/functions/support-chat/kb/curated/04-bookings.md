# הזמנה חדשה
אפשר לפתוח הזמנה חדשה מכמה מקומות:
- בטלפון: כפתור **+** העגול באמצע הסרגל התחתון.
- במחשב: כפתור **הזמנה חדשה** בראש המסך.
- במסך **הזמנות**: כפתור **הזמנה חדשה**.
- ב**לוח שנה**: נוגעים במשבצת פנויה.

ממלאים: **שם אורח** (חובה), טלפון ואימייל, **נכס** (היחידה), **ערוץ** (ישיר / Booking.com / Airbnb), **תאריך כניסה** (חובה) ותאריך יציאה, מחיר כולל (₪), סטטוס והערות. מספר הלילות מחושב לבד. לוחצים **שמירת הזמנה**.
אפשר לשמור עם שם ותאריכים בלבד ולהשלים את השאר אחר כך.

## שתי הזמנות על אותם תאריכים
אם התאריכים חופפים להזמנה אחרת באותה יחידה, המערכת מתריעה ולא מאפשרת לשמור, כדי למנוע כפילות.

# רשימת ההזמנות
**הזמנות**: כל ההזמנות מכל הערוצים. אפשר:
- לחפש לפי שם אורח.
- לסנן: כל ההזמנות / ממתינות לאישור / דורש תשומת לב, ובכפתור **סינון** גם לפי מצב, תאריכי כניסה ויחידה.
- **ייצוא**: מוריד את ההזמנות לקובץ CSV שנפתח באקסל.

# פרטי הזמנה
לוחצים על הזמנה ונפתח מסך הפרטים: האורח, התאריכים, היחידה, הערוץ, התשלומים, יתרה לתשלום, הערות. משם אפשר:
- **שליחה בוואטסאפ** לאורח (פותח וואטסאפ עם הודעה מוכנה).
- **שיחה** לאורח או **אימייל**.
- **רישום תשלום** (מקדמה, יתרה או תשלום מלא) ו**סימון כשולם**.
- **עריכה** של כל הפרטים.
- **מחיקת הזמנה**.

# מצבי הזמנה
ממתינה, מאושרת, מאושרת סופית, בשהייה, הסתיימה, בוטלה. משנים מצב ב**עריכה** של ההזמנה (שדה "סטטוס"). במסך **היום** יש גם כפתורים מהירים לסימון שהאורחים נכנסו או יצאו.

# ביטול הזמנה
עדיף לבטל ולא למחוק, כדי שההיסטוריה תישאר: פותחים את ההזמנה ← **עריכה** ← סטטוס **בוטלה** ← שמירה. התאריכים מתפנים בלוח.
שימו לב: ביטול במערכת atlas לא מבטל את ההזמנה ב-Booking.com או ב-Airbnb. שם צריך לבטל באתר של הערוץ.

# מחיקת הזמנה
בפרטי ההזמנה ← **מחיקת הזמנה** ← מאשרים. מיד אחרי המחיקה מופיעה הודעה עם אפשרות לבטל את המחיקה.
