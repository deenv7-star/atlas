# המסך לא נטען / מסך לבן / "לא הצלחנו לטעון"
1. בודקים חיבור לאינטרנט. בראש המסך מופיעה הודעה כשאין חיבור.
2. לוחצים **לנסות שוב** אם מופיע, או מרעננים את הדף (במחשב F5, בטלפון מושכים למטה או סוגרים ופותחים).
3. עדיין לא? סוגרים את הלשונית ופותחים מחדש את atlas-il.com. בכרום/ספארי מעודכנים זה עובד הכי טוב.
4. אם זה חוזר, **דבר עם נציג** וכתבו באיזה מסך זה קרה ומה ראיתם.

# שמרתי ולא נשמר / "לא ניתן לשמור"
- הודעה "ייתכן שהתאריכים תפוסים": יש הזמנה אחרת באותה יחידה על אותם תאריכים. בודקים בלוח השנה.
- שדות חובה: בהזמנה חובה שם אורח ותאריך כניסה. בליד חובה שם.
- אם יצאתם מהחשבון באמצע, נכנסים שוב ומנסים.

# הזמנה מ-Booking / Airbnb לא מופיעה
atlas מושכת את הערוצים כל 15 דקות, אז הזמנה מהדקות האחרונות יכולה לחכות לסנכרון הבא. אפשר ללחוץ **סנכרן עכשיו** ב**ערוצים וחיבורים**. אם עדיין לא מופיעה: בודקים שהערוץ מחובר ליחידה הנכונה ושאין ליד הערוץ שגיאה או "הזמנה כפולה אפשרית" (ראו "חיבור Booking.com ו-Airbnb").

# הזמנה "נעלמה"
- בודקים את הסינון במסך הזמנות (**ניקוי הסינון**), ואת מצב ההזמנה: הזמנה שבוטלה עדיין מופיעה בסינון "כל ההזמנות".
- במחשב, אם בחרתם יחידה אחת בכפתור הבניין בראש המסך, רק היא מוצגת. בוחרים "כל היחידות".
- הזמנה שנמחקה אפשר לשחזר רק מיד אחרי המחיקה, בהודעה שמופיעה. אחרי זה פונים לנציג.

# וואטסאפ לא נפתח
- צריך מספר טלפון בהזמנה.
- במחשב, הקישור פותח את WhatsApp Web או את אפליקציית וואטסאפ למחשב. צריך להיות מחוברים לוואטסאפ שם.
- בטלפון, אם נפתח דפדפן במקום וואטסאפ, בודקים שאפליקציית וואטסאפ מותקנת.

# לא מגיע מייל (אימות / איפוס סיסמה)
בודקים בספאם ובקידומי מכירות, מחכים כמה דקות, ולוחצים **שליחה חוזרת**. בודקים שהמייל הוקלד נכון. אם עדיין לא הגיע, **דבר עם נציג**.
