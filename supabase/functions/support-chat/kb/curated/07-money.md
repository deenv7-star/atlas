# איפה נמצא
**כספים** (במחשב בתפריט, בטלפון **עוד ← כספים**). יש בו לשוניות: **תשלומים**, **יתרות**, **חשבוניות**, **הוצאות** (כשהמסך פעיל בחשבון שלכם) ו**דוח חודשי**.

# רישום תשלום מאורח
הדרך הכי נוחה היא מתוך ההזמנה:
1. פותחים את ההזמנה ← **רישום תשלום**.
2. בוחרים סוג: **מקדמה**, **יתרה** או **תשלום מלא**, סכום (₪), אמצעי תשלום (מזומן, העברה בנקאית, כרטיס אשראי, ביט, פייבוקס, אחר), תאריך יעד וסטטוס.
3. **הוסף תשלום**. תשלום שעוד לא התקבל אפשר לסמן אחר כך ב**סימון כשולם**.
אפשר גם מ**כספים ← תשלומים ← תשלום חדש**.

התשלום מופיע בהזמנה, במסך היום ובכספים. "יתרה לתשלום" בהזמנה = המחיר הכולל פחות התשלומים שנרשמו.

## חשוב: ATLAS לא סולקת כסף
ATLAS רושמת תשלומים ועוזרת לעקוב אחרי מה שולם ומה פתוח. היא לא גובה בפועל מכרטיס אשראי ולא מעבירה כסף. את הכסף מקבלים כמו היום (ביט, העברה, מזומן, מסוף אשראי), ורושמים אותו ב-ATLAS.

# יתרות ומקדמות
**כספים ← יתרות**: מה שולם, מה נשאר ומי באיחור. סינון: פתוחות / באיחור / שולמו / הכול. לכל הזמנה יש **תשלום התקבל** (רושם את היתרה כשולמה) ו**תזכורת בוואטסאפ** לאורח.
את גובה המקדמה הקבועה (בלי מקדמה, תשלום מלא, או מקדמה על לילה אחד) קובעים בהגדרת העסק: **הגדרות ← ארגון ← פתיחת ההגדרה**, מסך "איך האורחים משלמים?".

# חשבוניות
**כספים ← חשבוניות ← חשבונית חדשה**: אפשר ליצור מסמך (חשבונית, קבלה, חשבונית מס, חשבונית עסקה) ולקשר להזמנה, לחפש, לסנן ולראות תצוגה מקדימה.
מה חשוב לדעת:
- המסמכים ב-ATLAS הם לתיעוד ומעקב. ATLAS היא לא תוכנת הנהלת חשבונות מאושרת ולא מפיקה מספר הקצאה של רשות המסים. חשבונית מס רשמית מפיקים בתוכנה שלכם (למשל חשבונית ירוקה/Morning או iCount).
- הכפתור **שליחה במייל** עדיין לא שולח מייל בפועל, רק מסמן את החשבונית כנשלחה. בינתיים שולחים לאורח את המסמך בעצמכם.

# דוח חודשי לרואה החשבון
**כספים ← דוח חודשי**: הכנסות לפי ערוץ, הוצאות, נטו, תפוסה ומחיר ממוצע ללילה. בוחרים חודש בחצים, ואז **ייצוא CSV** (נפתח באקסל) או **הדפסה / PDF**.

# הוצאות
**כספים ← הוצאות ← הוצאה חדשה**: נכס, קטגוריה (ניקיון, תחזוקה, ארנונה, חשמל, מים, ציוד, שיווק, אחר), סכום, תיאור וקבלה. רואים סה"כ הוצאות ורווח נקי משוער.
אם מופיע "מעקב הוצאות יגיע בקרוב", המסך עוד לא הופעל בחשבון שלכם (ראו "מה עוד לא עובד").

# הכנסות במסך היום
במסך **היום** יש "הכנסות החודש" מול החודש שעבר, תפוסה וגרף הכנסות (יומי / שבועי / חודשי). לחיצה על כרטיס ההכנסות מובילה לכספים.
