# לידים
**לידים** (במחשב בתפריט, בטלפון **עוד ← לידים**): כל פנייה של מי שמתעניין ועוד לא הזמין, מוואטסאפ, טלפון, פייסבוק או האתר.
- **ליד חדש**: שם, טלפון, אימייל, מקור, יחידה, תאריכים מבוקשים, מספר אורחים, תקציב והערות.
- חיפוש לפי שם, טלפון או אימייל, וסינון לפי מצב: חדש, בטיפול (נוצר קשר), הצעה נשלחה, נסגר, לא רלוונטי.
- ייצוא לידים לקובץ CSV.

# הפיכת ליד להזמנה
פותחים את הליד ← **הפוך להזמנה**. נוצרת הזמנה במצב "ממתינה" עם השם, הטלפון, התאריכים והיחידה של הליד, ונפתח מסך ההזמנה. הליד מסומן כנסגר.

# שינוי מצב ליד
בפרטי הליד, בשדה **מצב הליד**. ההערות בליד נשמרות לבד כשיוצאים מהשדה.

# לידים מדף הזמנה ישירה
כשדף ההזמנה הישירה פעיל, כל בקשה שאורח שולח מהדף נכנסת ללידים (ראו "דף אורח והזמנה ישירה").
