# שליחת וואטסאפ לאורח
1. פותחים את ההזמנה (מ**הזמנות**, מ**לוח שנה** או ממסך **היום**).
2. לוחצים **שליחה בוואטסאפ**.
3. בוחרים תבנית: **אישור הזמנה**, **הוראות הגעה**, **ברוכים הבאים**, **תודה ובקשת ביקורת** או **תזכורת יתרה**. ATLAS ממלאת לבד את שם האורח, התאריכים, היחידה, הניווט ואת היתרה.
4. נפתח וואטסאפ (באפליקציה בטלפון או ב-WhatsApp Web במחשב) עם ההודעה מוכנה לשיחה עם האורח. בודקים ולוחצים שליחה בוואטסאפ עצמו.

ההודעה יוצאת מהוואטסאפ שלכם, מהמספר שלכם. צריך שיהיה לאורח מספר טלפון בהזמנה. מספרים ישראליים כמו 0521234567 מתורגמים לבד לפורמט הבינלאומי.
במסך **היום** מופיע "הודעות מחכות לשליחה" עם כפתור **שליחה** להודעות שכדאי לשלוח היום.
תזכורת יתרה בוואטסאפ אפשר לשלוח גם מ**כספים ← יתרות** (כפתור **תזכורת בוואטסאפ**).

## לשנות את חתימת ההודעה
את משפט הסיום ואת שם החתימה בהודעת האישור קובעים בהגדרת העסק: **הגדרות ← ארגון ← פתיחת ההגדרה**, במסך "הודעת אישור בוואטסאפ".
פרטים כמו וויי-פיי, הוראות הגעה, כללי המקום ויעד לניווט נכנסים להודעות מ**עוד ← דף אורח והזמנה ישירה** (כשהמסך פעיל בחשבון שלכם).

# מסך הודעות
**הודעות** (במחשב בתפריט, בטלפון תחת **עוד**): רשימת השיחות עם אורחים ולידים וההודעות שנרשמו. אפשר לחפש לפי שם אורח ולכתוב הודעה.
חשוב: מה שכותבים במסך הזה נשמר כתיעוד ב-ATLAS. כדי שהאורח באמת יקבל את ההודעה, שולחים אותה דרך **שליחה בוואטסאפ** מתוך ההזמנה.

# אוטומציות
**עוד ← אוטומציות**: אפשר ליצור כללים כמו "שלח WhatsApp יום לפני כניסה", ויש תבניות מוכנות (תזכורת תשלום מקדמה, הודעת אישור הזמנה, יצירת משימת ניקיון, בקשת ביקורת).
חשוב לדעת: כרגע האוטומציות נשמרות אבל עוד לא רצות לבד. ATLAS לא שולחת הודעות אוטומטיות בלי לחיצה שלכם, ולא מחוברת ל-WhatsApp Business API. השליחה היום היא בלחיצה אחת מכל הזמנה (ראו למעלה). ברגע שהשליחה האוטומטית תהיה מוכנה, נעדכן.

# SMS ומייל
אין כרגע שליחת SMS. כפתור **אימייל** בהזמנה פותח את תוכנת המייל שלכם עם כתובת האורח.
