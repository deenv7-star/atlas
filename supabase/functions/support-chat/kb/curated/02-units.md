# הוספת יחידה (חדר, צימר, דירה)
היחידות מוגדרות במסלול הקצר של הגדרת העסק:
1. **הגדרות ← ארגון** (בטלפון: **עוד ← הגדרות ← ארגון**).
2. בכרטיס **הגדרת העסק** לוחצים **פתיחת ההגדרה**.
3. מתקדמים עם **המשך** עד המסך "כמה אורחים, ומה המחיר ללילה?" (רשימת היחידות).
4. לוחצים על כפתור ההוספה מתחת לרשימה. השם שלו לפי סוג העסק: "הוספת צימר", "הוספת חדר", "הוספת דירה" וכו'.
5. ממלאים שם, כמה אורחים ומחיר ללילה, ואפשר להוסיף תמונה. הכל נשמר לבד כשממשיכים.

טיפ: אם בחרתם בסוג העסק "צימר" או "וילה" (מקום אחד), ויש לכם יותר מיחידה אחת, חזרו למסך "איזה עסק יש לכם?" ובחרו "מתחם צימרים" או סוג אחר שמתאים לכמה יחידות.

# עריכה ומחיקה של יחידה
באותו מסך יחידות: לוחצים **עריכה** ליד היחידה כדי לשנות שם, מספר אורחים, מחיר או תמונה, או **הסרה** כדי למחוק אותה.
שימו לב: מחיר ללילה הוא מחיר בסיס. בכל הזמנה אפשר לרשום מחיר כולל אחר.

# כמה יחידות אפשר
אין הגבלה על מספר היחידות בתוך המתחם. המסלולים נבדלים רק במספר המתחמים (ראו "מחירים ומסלולים"): מתחם אחד עם כמה צימרים או חדרים הוא מתחם אחד.

# איפה רואים את היחידות
- **לוח שנה**: שורה לכל יחידה.
- **היום**: כרטיס המתחם מראה כמה יחידות מאוכלסות הלילה וכמה פנויות.
- בהזמנה חדשה בוחרים לאיזו יחידה היא שייכת (שדה "נכס").
- במחשב, אם יש יותר מיחידה אחת, כפתור הבניין בראש המסך מסנן את התצוגה ליחידה אחת.
